## Prompt 1 — Lamborghini Urus Pull-Up

A stylish young man steps out of a matte black Lamborghini Urus parked on a downtown street at golden hour. He's wearing an oversized structured blazer over a graphic tee, stacked cargo pants, and chunky designer sneakers. He adjusts his sleeve, does a slow 360 spin for the camera, then leans back against the SUV with arms crossed. Cinematic shallow depth of field, warm amber light bouncing off the paint. Tripod locked, 9:16 vertical.

### CLI quick reference

```bash
# Example — Marketing Studio still, one product, 9:16 white luxury studio
PRODUCTS_FILE=$(mktemp)  # or a .json path on Windows
printf '["f9e0e9e7-ffce-4cd5-b0f1-45ab0e083ca0"]' > "$PRODUCTS_FILE"

higgsfield generate create marketing_studio_image \
  --prompt "<paste white prompt from Pairing 1>" \
  --product_ids @"$PRODUCTS_FILE" \
  --aspect_ratio 9:16 \
  --resolution 2k \
  --wait
```

Replace `product_ids` with the UUID from each pairing. For **SKU-accurate** wardrobe without Marketing Studio retrieval, use `higgsfield product-photoshoot create --mode virtual_model_tryout --image <primary_png_url_or_file> --prompt "<white studio excerpt>"`.

**PowerShell (Windows)** — same job:

```powershell
$pf = New-TemporaryFile
'["f9e0e9e7-ffce-4cd5-b0f1-45ab0e083ca0"]' | Set-Content $pf.FullName
higgsfield generate create marketing_studio_image `
  --prompt "<paste white prompt from Pairing 1>" `
  --product_ids "@$($pf.FullName)" `
  --aspect_ratio 9:16 `
  --resolution 2k `
  --wait
```
